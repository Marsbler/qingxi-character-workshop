## 9. 常见问题

| 现象 | 处理 |
|------|------|
| `python` 不是内部命令 | 安装 Python 并勾选 Add to PATH，或用 `py -3.11` |
| `Activate.ps1` 禁止运行 | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| `ModuleNotFoundError: gradio` | `pip install gradio` 且确认已激活 venv |
| `ModuleNotFoundError: src` | 必须在 `character-workshop` 目录下执行（含 `app.py` 的那一层） |
| 端口 7860 被占用 | `$env:PORT=7861; python app.py` 或关掉占用进程 |
| 忘记设 MOCK，真推理报错 | 本地务必 `$env:MOCK="1"`；真模型只在 Radeon Cloud 测 |
| 中文路径乱码 | 用上面完整带引号的 `cd "..."` 路径 |
| pytest 找不到 | `pip install pytest`，在 venv 内执行 |
| UI 能开但生成很慢 | MOCK 应很快；检查是否 `MOCK=0` 且在下模型 |

确认当前 MOCK：

```powershell
python -c "import os; print('MOCK=', os.environ.get('MOCK'))"
```

## 11. 和「云上真推理」的边界（避免测错）

| 模式 | 命令 | 测什么 |
|------|------|--------|
| **本地 MOCK** | `$env:MOCK="1"` | 流程、UI、合成卡、测试（本指南） |
| **Radeon 真推理** | `$env:MOCK="0"` + ROCm + 下模型 | 真实画质/视频（另见 README Cloud 章节） |

本地 **不要** 以「出图像不像二次元大作」为 MOCK 通过标准；MOCK 立绘是占位图。看的是：**流程通、卡合成对、交互不崩**。
